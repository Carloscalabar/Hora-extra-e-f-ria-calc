# Hora extra e férias

Calculadora de hora extra (50%, 65% e 100%), férias e rescisão, feita como PWA. Funciona offline e pode ser instalada no celular.

## Publicar no GitHub Pages

1. Envie estes arquivos para um repositório público no GitHub (branch `main`).
2. Vá em **Settings → Pages**.
3. Em **Source**, escolha **Deploy from a branch**, branch **main**, pasta **/ (root)**, e salve.
4. Aguarde 1 a 2 minutos. O link aparece no topo da página: `https://SEU_USUARIO.github.io/NOME_DO_REPO/`

## Instalar no celular

Abra o link no Chrome e toque em **Instalar app** (ou menu ⋮ → **Adicionar à tela inicial**).
